# Citace a zdroje

## Použité zdroje

- Harvard CS50 Web Programming with Python and JavaScript, Project 0: Search. Zadání a očekávané funkce vyhledávání: <https://cs50.harvard.edu/web/projects/0/search/>
- Google Search. Formuláře odesílají vyhledávací dotazy na veřejný endpoint <https://www.google.com/search>.
- Google Advanced Search. Inspirační zdroj pro pole pokročilého vyhledávání: <https://www.google.com/advanced_search>
- W3C Markup Validation Service: <https://validator.w3.org/>
- W3C CSS Validation Service: <https://jigsaw.w3.org/css-validator/>

## Použitý prompt

Zadání od uživatele: vytvořit projekt podle CS50 Web Project 0 (Google Search, Image Search a Advanced Search), doplnit stránku s různými typy formulářových prvků, přidat na všechny stránky odkazy na validaci HTML/CSS a citace, přidat odkaz na portfolio a upozornit na nefunkční ukázkové formuláře.

## Poznámka k ukázkovému formuláři

Formulář na stránce `forms.html` slouží pouze k ukázce HTML prvků. Nic neodesílá ani neukládá; odesílací tlačítko je záměrně deaktivované.
